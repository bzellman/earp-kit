# System Design Workflows

## Purpose
Use this file for step-by-step system design workflows and review checklists.

## Workflow
1. Clarify goals, constraints, and scale
2. Define core entities and data flows
3. Choose boundaries and integration patterns
4. Identify bottlenecks and failure modes
5. Validate with trade-off analysis

## Review Checklist
- Data ownership and consistency
- Observability and SLOs
- Security and auth boundaries
- Scalability hotspots
- Operability and deployment
