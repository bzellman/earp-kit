# Architecture Patterns

## Purpose
Use this file for architecture patterns, best practices, and anti-patterns. Expand with concrete examples as you collect them.

## Common Patterns
- Layered architecture
- Hexagonal (ports/adapters)
- Event-driven
- CQRS
- Microservices vs. modular monolith

## Anti-Patterns
- Shared database across services without clear ownership
- Over-splitting services before clear boundaries exist
- Tight coupling between UI and persistence
