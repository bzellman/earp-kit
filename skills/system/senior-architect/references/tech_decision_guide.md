# Tech Decision Guide

## Purpose
Use this file to document stack decision frameworks and common trade-offs.

## Decision Factors
- Team expertise and hiring
- Latency and throughput needs
- Deployment and ops constraints
- Vendor lock-in and cost
- Ecosystem maturity

## Example Trade-offs
- GraphQL vs REST
- Postgres vs NoSQL
- Serverless vs long-running services
- Native vs cross-platform mobile
